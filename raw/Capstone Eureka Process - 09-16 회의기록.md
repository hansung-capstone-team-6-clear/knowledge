# 9/16 회의기록

## 1. 시나리오 아이디어 공유

김리윤 :
- **누가:** 신입 개발자 김지훈

- **언제·어디서:** 평일 오전 9시, 자기 자리 데스크펫 앞

- **발화:** “오늘까지 API 문서 정리 업무 등록해줘” / “오늘 할 일 뭐 남았어?”

- **데스크펫 기능:** STT → NLU로 업무명·마감 파싱 → Eureka Process 등록/조회 API 호출

- **Eureka Process 상태 변화:** 신규 업무 생성, 상태 “진행 전”

- **사용자 반응:** TTS 확인 응답 + LED 점멸 + LCD 텍스트 표시

김지훈 : 팀원 간 업무를 위임한다.
- **누가:** 팀 리더 김리윤 → 팀원 박시현

- **언제·어디서:** 오후 2시, 각자 자리의 서로 다른 데스크펫

- **발화:** “경쟁사 분석 자료 조사, 시현이한테 넘겨줘. 오늘 5시까지”

- **데스크펫 기능:** 담당자·업무·마감 파싱 → Eureka Process에 업무 생성 및 담당자 지정 → 상대방 디바이스에 실시간 푸시

- **Eureka Process 상태 변화:** 시현 계정으로 업무 생성, “배정됨” → 확인 시 “확인됨”

- **사용자 반응:** 시현 펫 LED·음성 알림, 확인 후 리윤 펫에도 역알림

박시현 : 자동차에 설치하여 이동 중 업무 일정을 조회한다.
- **누가·언제·어디서:** 박시현, 오전 10시 45분, 외근 나가기 직전 자기 자리

- **상황:** 오전 11시 A사 미팅이 예정되어 있고, 미팅 장소인 강남까지 차로 약 20분 소요

- **발화:** “다음 일정 뭐야?”

- **데스크펫 기능:** Eureka Process에서 현재 시각 기준 가장 가까운 예정 업무·일정을 조회하고, 이동 소요시간 정보가 있으면 도착 가능 여부를 함께 계산

- **조회 결과:** 11시 A사 미팅, 장소 강남, 이동시간 약 20분

- **여유 있는 경우:** TTS로 “다음 일정은 11시 A사 미팅이에요. 강남까지 차로 20분 걸리니까 지금 출발하면 여유 있게 도착해요.”라고 안내

- **사용자 반응:** LCD에 일정명·시간·장소 표시, LED 파란색 짧은 점멸로 “확인 완료” 표시

- **시간이 빠듯한 경우:** 남은 시간이 15분인데 도착까지 20분이 걸리는 등 여유가 부족하면 LED가 주황색으로 바뀌고, “서둘러야 할 것 같아요, 이동시간이 빠듯해요”처럼 경고성 톤으로 안내

이서현 : 출근하자마자 컴퓨터를 켜기 전에 오늘 일정을 조회한다.
- **누가·언제·어디서:** 직장인 A, 아침 9시 출근하자마자, 회사에서

- **상황:** 출근하여 자리에 앉아 본인의 컴퓨터가 켜지는 동안 오늘 일정을 조회하려고 한다.

- **발화:** “오늘 일정이 어떻게 돼?”

- **데스크펫 기능:** Eureka Process에서 오늘 예정 업무·일정을 조회하여 이를 한번에 정리해서 알려준다.

- **조회 결과:** 10시 스프린트 일정, 1시 타 부서에서 작성한 코드 점검, 4시 일일 업무 보고서 작성

- **Eureka Process 상태 변화: **없음

- **사용자 반응:** TTS 확인 응답 + LED 점멸 + LCD 텍스트 표시

## 3. 로봇 외형 아이디어 공유

김리윤 : 동물같은 친근한 외형. ex.앵무새

 혹은 한성대학교 마스코트 동물 활용. ex.거북이, 고양이

김지훈 : 고양이 귀 달린 시계(클로바 같은 디자인)

 LCD를 포함해야 하기 때문에 곡선형 보다는 평평한 디자인을 선호

박시현 : 우리가 구현할 수 있는 선에서 구현. ex.정육면체, 원기둥

 학교에서 제공하는 3D프린터에서 출력할 수 있는 크기 제한적

이서현 : 얼굴과 몸통으로 나뉜 로봇 외형.
